Spotify

Sur cette page, le timer ne peut pas piloter Spotify : elle bloque les connexions vers d'autres sites. Lancez votre playlist dans l'app Spotify, puis revenez ici. Les bips jouent par-dessus la musique. Pour que le timer contrôle Spotify (lecture, pause, baisse du volume pendant les bips), ouvrez la version hébergée de l'application.

Nécessite un compte Spotify Premium et un « Client ID » créé sur developer.spotify.com, avec cette adresse comme Redirect URI :
