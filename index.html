  1. Sur developer.spotify.com/dashboard, créez une app.
  2. Dans Redirect URIs, collez exactement cette adresse :
  1. Cochez Web API, enregistrez, puis ouvrez Settings et copiez le Client ID (pas le « Client secret »).
